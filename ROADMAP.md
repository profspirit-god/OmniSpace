# ROADMAP.md
Approved plan. Unapproved ideas live in `docs/PROPOSALS.md`.

## SECTION: Phase 0 - Shell (this commit)
Vite + React + TS, recursive module registry, sidebar and tab bar, dashboard animation, placeholders for every module, GitHub Pages deploy.

## SECTION: Phase 1 - Foundation
Local storage layer, settings, export/import/backup, error handling, password gate, simple/visual view toggle.

## SECTION: Phase 2 - Notes, journal, shopping
Second Brain with linked notes, journal linked to it, shopping templates with per-store prices and checklist.

## SECTION: Phase 3 - Calendar
Custom symbols, colored work view.

## SECTION: Phase 4 - Trackers
Progress tracker, streaks, workout tracker, body map with muscle highlight, body stats.

## SECTION: Phase 5 - Platforms
PWA install, APK (Capacitor), EXE (Tauri or Electron), optional Supabase sync.

## SECTION: Phase 6 - Assistant
In-app commands, fallback AI chain, assistant that operates the app through named commands.
